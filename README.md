# 金融借贷纠纷智能裁判与债权清算助理系统 (ClaimLex)

面向金融借贷诉讼、执行立案及不良资产清收场景，结合**大语言模型（LLM）语义要素提取**与**确定性司法规则精算引擎**，实现从“裁判文书/合同文本非结构化解析”到“跨期利率分段精算”，再到“法庭质证证据清单生成”的全流程自动化。

---

## 1. 业务痛点与项目定位

在传统金融审判与债权债务处置实践中，债权清算长期面临以下核心痛点：
* **文书要素非结构化**：判决主文与借款合同中充斥着复杂的法律表述（如“借款到期之日”、“按同业拆借中心公布的5年期以上LPR加60个基点上浮50%”、“未付利息按前述利率计收复利”），人工提取繁琐且容易漏项；
* **跨期利率核算极其复杂**：涉诉借贷纠纷跨度常长达数年甚至十数年，经历央行存贷款基准利率多次调整、2019年“换轨LPR”以及历月LPR非对称下调，人工拆分调息周期耗时费力且极易出错；
* **法庭质证合规要求严苛**：立案与执行阶段需要清晰列明每一笔本金、利息、罚息、复利以及《民诉法》加倍迟延履行期间债务利息的计算来源与明细依据。

本项目采用**大模型理解事实要素 + 规则引擎刚性精准测算**的融合技术路线，彻底解决上述痛点。

## 2. 核心功能与亮点

- **大模型驱动的司法要素抽取与审查**：
  支持直接粘贴判决书/借款合同正文，或上传 PDF 裁判文书。通过专业的司法审判 Prompt 引导大模型自动提取本金余额、债权基准日、利率定价模式（LPR/基准/固定）、加减BP、罚息倍数、复利计息范围及迟延履行金约定，并生成法律逻辑审查依据与裁判要点提炼。
- **开放的大模型 API 动态配置模块**：
  提供用户友好的可视化配置界面，支持自由录入 API URL、API Key、模型名称、版本、请求方法及自定义 Headers。内置 DeepSeek、Google Gemini、阿里通义千问、OpenAI、月之暗面 (Kimi)、硅基流动等主流模型预设，并支持本地私有模型（Ollama/vLLM）接入与一键连通性测试。
- **PDF 文本深度清洗与预处理引擎**：
  针对裁判文书网导出件及扫描件，自动清除页眉页脚、裁判文书网水印等结构噪声，修复中文字符位移孤立空格，并提供纯图片扫描件预警。
- **司法级确定性利息精算中枢**：
  内置 2000 年至今历次中国人民银行基准利率与全国银行间同业拆借中心 LPR 历史数据库，自动按调息日切割分段，严格遵循“算头不算尾”、“实际天数÷360天”、滚动利息与罚息复利、日万分之一点七五加倍迟延履行金等司法裁判规则，实现 0 误差清算。
- **加倍迟延履行金计算规则合规化改造（严格遵循法释〔2014〕8号）**：
  明确迟延履行金的计息基数边界 —— 仅限生效法律文书确定的“除一般债务利息之外的金钱债务”（本金 + 判决确认的诉讼、保全等固定费用），严禁将裁判后持续滚动的罚息、复利及一般利息纳入基数（杜绝“利滚利”）；并内置**基数归零熔断机制**，当本金及固定费用清偿完毕后立即停止计提加倍迟延履行金、日增量置为 0。
- **多模式还款抵充顺序引擎（Waterfall 机制）**：
  内置两种可切换的清偿顺序选项 —— **法定清偿顺序**（《民法典》第561条及执行解释：先费用及实现债权费用 → 次一般利息/罚息/复利 → 再本金 → 全部主债务清偿后再冲减加倍迟延金，默认推荐）与**商业优先冲本模式**（协商重组场景：还款全额优先冲减尚欠本金以快速压降计息基数 → 再冲罚息利息 → 费用 → 迟延金）。
- **判决确认诉讼费用并入执行标的池**：
  支持录入案件受理费、保全费/执行费，随本金、利息、罚息、复利共同组成执行标的清算池，并在还款流水冲减与司法证据中精细列示每一项的抵充流向。
- **银行扣款回单/还款流水解析与动态冲减算息**：
  支持上传《个人贷款扣款回单》PDF 或流水清单，自动提取借据号、贷款日期、归还本金/利息/罚息/复利等字段，逐笔勾选是否参与算息，系统自动按还款节点切割分段并动态冲减计息基数。
- **批量案件客户靶向选择器**：
  针对带《原告诉讼请求附表》的消金批量诉讼系列案，自动解析多名借款人明细，可选择任一客户独立清算并联动切换案号、本金、利息及诉讼费用，一键生成对应质证清单。
- **Human-in-the-Loop 人机协同微调**：
  提取出的全部要素均在界面上结构化直观展示，法务人员可按审判实际进行手动复核与参数微调（含抵扣策略、诉讼费用、履行期届满日等），系统即刻触发毫秒级热重算。
- **司法级证据制式清单与《执行款分配与结清确认表》交付**：
  一键导出符合法庭质证规范的“法院蓝”制式 Excel 证据清单底稿，包含案卷基本信息、裁判主文摘要、6大汇总清算指标以及逐日分段计息流水明细；并在独立 Sheet 生成《执行款分配与结清确认表》，涵盖执行标的清算池、还款抵充与冲销分配汇总、最终执行结欠净额及逐笔流水抵充分配明细，满足执行立案、庭审质证与破产对账的严苛司法证据要求。

## 4. 司法清算核心合规规则

### 4.1 迟延履行加倍金的合规化计算（法释〔2014〕8号）

- 加倍部分债务利息严格遵循《最高人民法院关于执行程序中计算迟延履行期间的债务利息若干问题的解释》（法释〔2014〕8号）第一条：
  `加倍部分债务利息 = 尚未清偿的生效法律文书确定的除一般债务利息之外的金钱债务 × 日万分之一点七五 × 迟延履行期间天数`。
- **计息基数边界**：基数仅限生效裁判确定的借款本金及判决确认的诉讼、保全等固定费用；裁判后持续滚动的一般利息、罚息、复利一律不作为基数，杜绝“利滚利”。
- **基数归零熔断机制**：当冲减结算后本金及固定费用全部清零时，系统立即停止生成新的加倍迟延履行金分段，日增量强制置为 0，并在界面与证据清单中标注熔断状态与法律依据。

### 4.2 多模式还款抵充顺序（Waterfall 引擎）

系统内置两种可即时切换的清偿顺序策略，并全程生成逐笔流水抵充分配明细：

- **选项 1：法定清偿顺序（执行程序标准，默认推荐）** —— 依《民法典》第561条及执行解释第四条：优先清偿生效法律文书确定的费用及实现债权的费用 → 次冲一般利息/罚息/复利 → 再冲减借款本金 → 全部主债务清偿完毕后仍有余额才冲减加倍迟延履行利息。
- **选项 2：商业优先冲本模式（协商重组场景）** —— 还款全额优先冲减尚欠借款本金（快速降低计息基数以节约罚息）→ 剩余再依次冲减罚息、利息、复利 → 费用 → 加倍迟延金。

### 4.3 《执行款分配与结清确认表》

在“法院蓝”制式 Excel 中生成独立的《执行款分配与结清确认表》，作为法院执行立案与对账的司法级证据，包含：

- **一、执行标的清算池**：生效裁判本金、案件受理费、保全费/执行费、期初历史欠息罚复利、裁判后新发生息费及加倍迟延金的总申报标的；
- **二、还款抵充与冲销分配汇总**：累计抵充费用、利息、本金、迟延金及溢缴款的流向与结清状态；
- **三、最终执行结欠净额确认**：尚欠本金/费用/息费/迟延金及申请执行总净额，含熔断标识；
- **四、单笔还款抵充分配流水明细**：逐笔展示每笔还款金额在费用、利息、本金、迟延金间的 Waterfall 分配流向与超额溢缴款。

## 5. 本地运行与开发

### 环境准备
确保本地已安装 [Node.js](https://nodejs.org/)（推荐 Node 18+）。

### 安装与启动
```bash
# 1. 安装项目依赖
npm install

# 2. 启动本地开发服务器
npm start
```
开发服务器启动后，在浏览器中访问 `http://localhost:5173/` 即可打开系统看板。

### 使用流程
1. 点击顶栏右上角的 **“模型配置”** 按钮；
2. 填入或选择您的大模型 API 地址、模型标识（如 `deepseek-chat`、`gemini-1.5-flash`）及 API Key，测试连通后保存；
3. 上传裁判文书 PDF，或点击载入 **单一案件样例 / 批量案件附表样例 / 银行扣款回单流水样例**；对于批量系列案，可在附表中选择任一客户并切换清算；
4. 点击 **“⚡ 启动真实大模型智能解析与债权清算”**，生成要素提取报告与分段利息清单；
5. 在**人机协同校验区**复核并微调参数（本金/利息、诉讼与保全费、利率、罚息倍数、履行期届满日），并选择 **还款抵扣策略（法定清偿顺序或商业优先冲本）**，系统即刻热重算；
6. 查看核心清算指标、《执行款分配与结清确认表》与逐笔还款抵充明细；
7. 点击 **“导出‘法院蓝’制式 Excel 证据清单”**，获得含分段计息流水、《执行款分配与结清确认表》及银行扣款流水的司法级对账证据底稿。
