# 基于大模型 Agent（TRAE Skill）的金融借贷纠纷智能裁判与债权清算助理

## 1. 项目定位
本项目旨在跳出传统的“利息计算工具”范畴，重塑为 **AI Agent 驱动的金融纠纷智能解纷平台**。通过集成大模型（LLM）的语义理解能力与 TRAE Skill 的高精度司法级计算引擎，实现从“文书解析”到“精准清算”再到“证据生成”的全链路自动化。

## 2. 核心亮点
- **Agent + Tool 复合架构**：利用 LLM 解析复杂的裁判文书、起诉状等非结构化数据，自动提取关键裁判要素；调用 TRAE Skill 确定性执行引擎进行 100% 零误差的利息清算。
- **直击行业痛点**：针对金融借款纠纷中跨期长（2000年至今）、规则杂（基准利率转 LPR、罚息、迟延履行金）、核算难等重灾区，提供秒级解决方案。
- **司法级交付物**：自动生成符合法庭质证标准的“法院蓝”制式 Excel 证据清单与交互式 HTML 报告。
- **高落地可行性**：封装为标准化 Skill，可无缝嵌入全行业务系统或协同办公工具。

## 3. 技术架构
- **感知层 (Perception)**：基于 LLM 的要素解析引擎，支持自然语言输入与 PDF/Word 文书解析。
- **逻辑层 (Logic)**：TRAE Skill 司法级精确计算中枢，内置历年基准利率、LPR 数据库及复杂分段算法。
- **展现层 (Presentation)**：响应式 Web 交互界面 + 多模态标准化报告导出。
- **系统层 (System)**：基于 TRAE 能力编排，实现 Agent 与 Tool 的高效协同。
